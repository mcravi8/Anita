# Connection logos

These marks identify the services Buddy connects to. They belong to their respective owners and are not Buddy branding. Keep the supplied shapes, proportions, and colors; do not redraw or tint them.

| Asset | Official source |
| --- | --- |
| `openai.svg` | Exact Blossom SVG from the [OpenAI Developers](https://developers.openai.com/) header; [brand guidelines](https://openai.com/brand/) |
| `claude.svg`, `anthropic.svg` | Claude Spark – Clay and Anthropic symbol – Slate from [Anthropic’s press kit](https://www.anthropic.com/press-kit), linked by its [newsroom](https://www.anthropic.com/news) |
| `gmail.svg`, `google-drive.svg`, `google-calendar.svg` | Google Workspace [official artwork](https://knowledge.workspace.google.com/admin/getting-started/brand-your-internal-communications-with-google-workspace), served from that page’s `static/images/icons/product/` directory |
| `google-contacts.png` | [Google’s product artwork](https://www.gstatic.com/images/branding/product/2x/contacts_2022_48dp.png) |
| `sites.svg`, `chatgpt-space.svg`, `pets.svg` | Exact logo assets from the installed OpenAI Sites, Pages, and Pets plugin packages |
| `github.svg` | GitHub Invertocat – Black from the [official logo kit](https://brand.github.com/foundations/logo) |

Other connections use their `iconUrl` supplied by the installed app’s official connection metadata. Images are decorative beside the visible service name, use HTTPS without a referrer, and fall back to a neutral capability icon if unavailable. The common bundled marks continue to work offline. No credential, permission, or connected-service behavior depends on these images.
